# QA checklist & common bugs

## Per-frame checklist (inspect a still at the middle of every scene and at each cut ±0.1 s)
- Nothing overlaps unintentionally; nothing clipped at the frame edge; labels inside the 96 px safe area.
- Text is spelled exactly as given, legible (≥ 28 px body, ≥ 20 px labels at 1080p), contrast ≥ 4.5:1.
- One clear focal point; no half-empty frame for > 1 s unless intended.
- Accent elements land exactly where intended (dots on letters, lines on baselines).
- Consistent palette, radius, stroke weights across scenes.
- The final frame is a strong, complete composition (it is also the thumbnail and the reduced-motion still).
- No visible counter/label text that contradicts the scene (e.g., "144 tiles" when there are 98).

## Motion checks (watch the MP4 once at 1×)
- Cuts land on the beat; sound hits match visual hits.
- No pops: elements do not appear/disappear without an entrance/exit unless it is a hard cut.
- Pacing breathes: at least one held moment; final hold ≥ 1 s.
- Duration exactly as briefed (`ffprobe`), audio not clipping (`volumedetect` max ≤ −1 dB).

## Common bugs → fixes
| Symptom | Cause | Fix |
| --- | --- | --- |
| Video timing differs from browser | Real-time clock used during capture | Use `__seek(i/fps)`; no `performance.now()` inside scenes |
| Frames flicker / differ between renders | `Math.random()` at draw time | Seeded `rnd(i)`; precompute randomness |
| Element jumps at a cut | Scene state not continuous | End scene A where scene B starts (shared position), or make it a deliberate match cut |
| Text off-center with letterSpacing | `measureText` measured without spacing, or trailing spacing | Set `ctx.letterSpacing` before measuring; subtract trailing spacing |
| Morph looks noisy | Poor point pairing / ends too late | Pair by sorted order (e.g., by angle or y), finish the morph by 70 % of the scene |
| Blend mode makes odd colors | `difference`/`exclusion` on colored tiles | Use solid knockout colors or offscreen `source-atop` |
| Blank frames in screenshots | WebGL without `preserveDrawingBuffer`, fonts not loaded | Set it true; `await document.fonts.ready` |
| No sound in browser | Autoplay policy | Start AudioContext on click |
| GIF banding | No palette | Use palettegen/paletteuse recipe |
| Choppy live playback | Heavy per-frame work | Cache static layers in offscreen canvases; reduce particles; avoid full-frame blur |
| Vertical version cramped | 16:9 layout reused | Re-layout: stack elements, reduce type by ~20 %, respect top/bottom UI zones |
| Scramble/decoding line slides sideways | Hidden letters replaced by spaces in a centered string | `drawScramble()` (glyphs locked to final positions) |
| Centered tracked text off-center | Canvas adds trailing letterSpacing | `textC()` or shift by −track/2 |
| Fallback font in MP4 | Font not loaded before capture | `await document.fonts.load(...)`, set `window.__ready` |
| Image missing in some frames | Captured before image loaded | Preload all assets, `window.__ready=true` after Promise.all |
| Video frame stuck | Seek not awaited | `await seekVideo(v,t)` inside async `__seek` |
| SFX silent in export | Library not decoded in the Offline context, or file:// blocked | `await loadLibrary(oac,…)` in `__renderAudio`; run with `--allow-file-access-from-files` |
| Audio too loud / distorted | Gains stacked, no limiter | Use makeMixer; check volumedetect (peak ≤ −3 dB) |
| Whoosh late | Started at the cut | `A.whoosh(cut)` peaks at the cut; samples use `hitAt` |
| Particles flicker | Random per frame | Seeded constants per particle |
| Particle text fuzzy at the end | Never resolved to real text | Crossfade to solid text in the last 0.15 s |
