# SVG Master Ugvay
1. Read `SVGMASTER.md` (API) and, per subject, `references/SUBJECTS.md`; follow `references/DESIGN.md`; biology/medicine → `references/BIO-ATLAS.md`; camera moves & 3D → `references/CAMERA.md`; find any item by shelf in `references/LIBRARY-INDEX.md` (223 types) and check accuracy in `references/FACTS.md`. Text layout is built in (SVGMASTER.md §5b); part of the UGVAY library (`LIBRARY.md`) — for promos/logos/reels use Code Motion Graphics instead.
2. Plan scenes (table), then write ONE HTML: `<script src="svgmaster.js"></script>` + `LESSON({...})`. Imitate `examples/`.
3. Check: `node scripts/qa-sheet.mjs lesson.html sheet.png` → look at the sheet, fix errors/overlaps.
4. Export: `node scripts/render-lite.mjs lesson.html lesson.mp4`.
