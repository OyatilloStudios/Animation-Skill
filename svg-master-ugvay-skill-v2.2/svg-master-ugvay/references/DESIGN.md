# Visual & animation principles (what "professional" means)
1. **Hierarchy:** one hero visual per scene; text supports it. Title top-left, captions bottom.
2. **Progressive disclosure:** reveal parts in the order you explain them (auto sequence or `at`). Never show everything at once.
3. **Motion has meaning:** arrows with `flow` for transport, `pulse` for attention, `camera` zoom to go deeper, `focus` to isolate. Avoid decorative motion that competes with content.
4. **Timing:** ~0.42 s per spoken word; hold the finished state ≥ 2 s; entrances 0.6–1.5 s.
5. **Color semantics:** a1 (cyan) = main object, a2 (amber) = highlight/accent, a3 (red) = danger/hot/arterial/negative, a4 (green) = correct/positive/life, a5 (violet) = secondary. Blue/red for venous/arterial blood, + red / − blue charges.
6. **Consistency:** same color for the same concept across scenes; same theme for whole lesson.
7. **Readability:** text ≥ 30 px at 1080p, ≤ 12 words per line, labels 1–3 words, ≤ 8 labels.
8. **Accuracy beats beauty.** Correct proportions of formulas, units, directions of arrows.
9. **Reels (9:16):** hook in first 2 s (title kind + strong `say`), 5–7 scenes, larger sizes, top/bottom areas.
10. **End strong:** quiz → summary (3–4 points) → thanks.
