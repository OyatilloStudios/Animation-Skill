# Prompt library & briefs

Contents: 1 Brief template · 2 Showreel · 3 Logo reveal · 4 Kinetic typography · 5 Seamless 3D loop · 6 Data story · 7 Product launch · 8 UI / app demo · 9 Explainer · 10 Social post loop · 11 Follow-up edit prompts

## 1. Brief template (fill before coding)
```
Purpose / platform:   e.g. Instagram Reel, YouTube intro, portfolio
Length & format:      15 s, 1920x1080 (or 1080x1920), 30 fps
Idea (one sentence):  e.g. "the red dot travels through every scene and becomes the logo's i"
Exact copy:           every word that appears on screen, verbatim
Data:                 exact numbers + source
Brand:                colors (hex), font, logo file
Mood & references:    e.g. Swiss, minimal, punchy, Apple-like, playful
Key moment:           e.g. "a satisfying hit when the logo lands"
Audio:                none / synthesized at N BPM / provided track / voiceover script
Deliverables:         HTML, MP4, GIF, vertical cut
```

## 2. Showreel (the prompt that went viral)
"Make a dynamic 15-second motion graphics video that shows what an incredible motion designer you are, like it's your showreel for a résumé. Go all out."
Beat sheet (128 BPM, 8 bars × 1.875 s): bounce w/ squash & stretch → per-letter slam → 3D point morph → grid wave → line ribbon → tunnel → full-accent numbers → logo where the through-line dot becomes a letter. One accent dot travels through every scene.

## 3. Logo reveal (5–8 s)
"8-second logo reveal for <brand>. Punchy and premium, with a satisfying hit when the logo lands. End on the logo with <url> underneath."
Beats: abstract tension (lines converge / particles gather, 0–3 s) → impact (logo slams or assembles on a sub-bass hit, 3–4 s) → light sweep (4–5 s) → tagline/URL rise (5–6 s) → hold. Ideas: build the mark from its own geometry; let a letter's detail (dot, bar, counter) become the moving hero.

## 4. Kinetic typography (10–15 s)
"Kinetic typography for the line '<quote>'. ~12 seconds, vertical for Reels. Every word moves on the beat."
Beats: one word or phrase per beat; vary the entrance per word type (verbs slam, nouns rise, emphasis word in accent color and larger); one bar of silence before the final phrase; end with the whole poster composed and a pull-back.

## 5. Seamless 3D loop (8–12 s)
"A seamless 10-second 3D loop: abstract shapes that morph and orbit in depth, hypnotic; the last frame flows into the first."
Rules: everything periodic in L; morph chain returns to the start shape; orbits make whole turns; export exactly L·fps frames.

## 6. Data story (15–20 s)
"15-second vertical motion graphic: <metric> went from A in <year> to B in <year>. Make the change feel dramatic."
Rules: numbers only from the user/source (cite on screen in small text); constant time scale so real acceleration shows; one comparison as the final card ("took 123 years → took 11"); direct labels instead of legends.

## 7. Product launch (20–30 s)
Beats: hook question (2 s) → product name slam (2 s) → 3 feature vignettes with UI mockups (4 s each) → social proof number (3 s) → logo + CTA + date (3 s). Use the user's screenshots as images inside device frames; animate cursor and clicks.

## 8. UI / app demo (10–20 s)
Device frame, cursor path on arcs, press states, list items staggering in, toast notification sliding, counters ticking. Keep UI text real and legible (≥ 28 px at 1080p).

## 9. Explainer (30–90 s)
Write the script first (≈ 2.5 words/s). Split into scenes per sentence. Style sheet: palette, type scale, icon style, transition vocabulary (2–3 types only). Generate TTS, take timestamps, then animate against them. Captions in a safe area.

## 10. Social post loop (5–8 s)
Square 1080×1080, one bold statement, background motion loop (grid/ribbon/blob), text appears with mask rise, loops seamlessly.

## 11. Follow-up edit prompts (how users iterate)
- "Slow scene 3 down by 1 bar." → change its duration in SCENES; shift later scenes.
- "Swap the accent to navy #1E3A8A." → change C.acc only.
- "Make it vertical." → W=1080,H=1920; re-layout with relative positions; type sizes ×0.8; re-check safe areas.
- "Replace the text with mine." → copy exactly; re-measure widths; check overflow.
- "More energy." → raise BPM, shorter scenes, bigger overshoot, more shake.
- "More premium." → slower eases (inOutQuint), less shake, more negative space, light sweep, softer sound.
